Confidentialité & données

Cette page explique simplement quelles informations peuvent être traitées quand vous utilisez L’apéro catalan®, pourquoi, et comment exercer vos droits (RGPD).

1

Ce que fait l’application

Une PWA (application web) d’accès rapide : catalogue, infos, appel direct.

  • Pas de création de compte.
  • Pas de paiement intégré dans l’application.
  • Une partie des réglages peut être enregistrée sur votre appareil (ex : confirmation d’âge, préférences d’affichage).
2

Données stockées sur votre appareil

Pour que l’expérience soit fluide, certaines infos peuvent être sauvegardées localement.

  • Vérification d’âge : mémorise votre choix pendant une durée limitée.
  • Cache / mode hors-ligne : le navigateur peut conserver des fichiers (images, pages) pour accélérer le chargement.
Ces données restent principalement sur votre appareil. Vous pouvez les effacer en vidant les données du navigateur (paramètres de Chrome/Safari) ou en désinstallant la PWA.
3

Mesure d’audience / statistiques (anonymisées)

Pour comprendre ce qui fonctionne (ex : clic “Appeler”, “Installer”), des événements peuvent être comptabilisés.

Quand vous cliquez sur certains boutons, l’application peut envoyer un événement de statistique vers une URL de suivi. Ces événements servent uniquement à améliorer l’expérience et piloter l’activité.

  • Exemples : clic sur Appeler, clic Installer, navigation de base.
  • Données techniques possibles : type d’appareil, navigateur, source (ex : “facebook”).

Exemple d’URL de suivi (format) :

https://stats.aperos.net/…
Objectif : statistiques globales. Pas de profilage publicitaire et pas de revente de données.
🔔

Notifications push

Alertes d’ouverture, informations importantes et offres ponctuelles.

L’application peut proposer l’activation des notifications push afin de vous informer de l’ouverture du service, d’informations importantes, d’offres ponctuelles ou de communications liées à L’apéro catalan®.

L’activation nécessite votre accord via la fenêtre d’autorisation de votre navigateur ou de votre appareil. Sans cet accord, aucune notification push ne peut être envoyée.

  • Données techniques possibles : identifiant d’abonnement push, navigateur utilisé, date d’inscription, dernière activité connue.
  • Cible : l’abonnement peut être associé au site concerné, par exemple « Apéro Catalan ».
  • Finalité : envoyer les notifications demandées et assurer leur bon fonctionnement.
Les notifications peuvent être désactivées à tout moment depuis les paramètres de votre navigateur, de votre téléphone ou en supprimant les données du site. Ces données ne sont pas revendues à des tiers.
4

Partage des données

Seulement avec les services nécessaires au fonctionnement.

  • Hébergement : site hébergé en statique et servi via HTTPS.
  • Statistiques : service technique de collecte (ex : via infrastructure Cloudflare / endpoint stats).
  • Notifications push : service technique d’envoi et de gestion des abonnements push, notamment via l’infrastructure Cloudflare.

Remarque : selon votre appareil, le navigateur / système peut aussi appliquer ses propres politiques (cache, journaux, etc.).
